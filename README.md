# Titanic-Survival-Analysis
"Titanic Survival Analysis using Excel and Power BI"

## Project Overview
Analyzed the Titanic dataset (20 passengers sample) to understand survival patterns using Excel and Power BI.

## Tools Used
- Microsoft Excel
- Microsoft Power BI

## Data
- Source: Kaggle (Titanic Dataset)
- Sample: 20 passengers
- Columns: PassengerId, Survived, Pclass, Name, Sex, Age, SibSp, Parch, Fare, Embarked

## Excel Work
- Added AgeGroup column using nested IF
- Created Pivot Table 1: Survived vs Died
- Created Pivot Table 2: Survival by Gender
- Found: Female survival = 82%, Male survival = 11%

## Power BI Dashboard
- 2 KPI Cards (Count of PassengerId, Sum of Survived)
- Pie Chart (Survived vs Died)
- Bar Chart (Survival by Gender)
- Slicer (Sex)

## Key Insights
1. Total Passengers: 20
2. Total Survived: 10
3. Overall Survival Rate: 50%
4. Female Survival Rate: 82%
5. Male Survival Rate: 11%

## Conclusion
Women had a much higher survival rate than men, which matches the historical "women and children first" policy.
